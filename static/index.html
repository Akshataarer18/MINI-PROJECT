Why versions matter

If Bob edits from version 1 after Alice has saved version 2, E1 flags Bob's request as stale instead of silently overwriting Alice's update.

Prototype scope

This demo uses in-memory storage and whole-document replacement. It is not yet a multi-machine real-time editor.
